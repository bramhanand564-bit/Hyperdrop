# Hyperdrop V0.1 Acceptance

V0.1 acceptance covers: task understanding, knowledge-gap routing, provider-based research, bounded page reading, Evidence records, provenance verification, conflict handling, compact answers, persistent compressed memory, tool registration and default-deny permissions, checkpoints/resume, failure recovery, runtime lifecycle, Android bridge boundaries, and offline testability.

V0.1 does not claim consciousness, human-level general intelligence, or unrestricted autonomous computer control. It is the stable foundation for stronger tools, Android execution, richer retrieval, and long-running workflows.
