# Hyperdrop

Hyperdrop is an experimental project for a persistent, tool-using AI system built around a living cognitive loop.

## Vision
**Goal → Understand → Detect unknowns → Research → Verify → Plan → Act → Observe → Reflect → Learn → Compress/Forget → Remember**

## V0.1
The first milestone is a research-capable cognitive core:
1. Receive a user goal.
2. Decide whether external research is needed.
3. Research when needed.
4. Verify information.
5. Produce an answer with uncertainty when appropriate.
6. Preserve only useful lessons, not all raw research.

## Architecture
- core/mind — cognitive controller
- core/memory — adaptive memory
- core/research — research orchestration
- core/verification — evidence and confidence checks
- core/planner — task decomposition
- core/agent — future tool execution
- core/learning — reflection and consolidation
- android — future Android application
- docs — design documents
